## 一、为什么要拓展：现状与痛点

**现状**（全部已实现）：

- 转生两条路：打到 MAX 按公式结算；或本周目首次到 LuV 弹「时空裂缝」，选转生固定给 1 条，
  选不转则本周目只剩 MAX 一条路
- 线缆公式：`floor(log₂(累计EU / 1e12)) × (1 + 0.1 × 最高电压) + (2x + 1)`
  校验值：1e40 / tier 13 / x=0 → 214 条
- 货币时空线缆**只有一个去向**：15 节点的永久加成树（3 支线 × 3 层，层价 1 / 2 / 6，全买满 51 条）
- 每次转生可选 1 个平行宇宙，选过的永久叠加（工业 / 奥术 / 深渊 / 硅基，四个都已实现）
- 重置本周目一切，保留线缆、树、宇宙、转生次数、累计统计

**痛点**（对应"内容太少"的四个具体缺口）：

1. **线缆会毕业**：树 51 条封顶。对照"打满一次 MAX 拿几十到上百条"，第二三次转生后
   树就买满了，之后每一条线缆都无处可花 —— 转生收益实质归零，只剩 (2x+1) 的保底数字在涨。
2. **转生时机没有决策**：裂缝是一次性的固定 1 条，MAX 是唯一大量来源。
   "这一周目什么时候转"不构成选择，玩家只会在同一个地方转。
3. **周目同质化**：周目之间的差异只来自宇宙组合，周目内部没有任何专属目标，
   打到 MAX 的过程每轮一模一样。
4. **MAX 之后没有终局**：普朗克电路等终极内容在计划书里还挂着"作用未定"。

**设计原则**（沿用计划书已立的规矩，不新发明）：

- 数值做小、靠层数与次数累积，一档 4%~8%，不做一步到位的大跳
- 转生是"分叉时间线"不是惩罚；每一条线缆都要有意义（裂缝给 1 条要能点亮一格）
- 风险由玩家主动选择（对应第六章"风险-回报杠杆"）
- 每个设计必须有现有系统的落点（吸取"升压暂缓"的教训：没有配方系统就不设计配方门槛）

## 三、M1 时空星图：加成树二期

**动机**：让 51 条之后的线缆继续有意义，同时把"宇宙、电网、污染、镐子"这些已有系统
接进永久成长。树从 3 支线扩到 6 支线，新增第四层。

**树的新结构**（在原 15 节点上追加，老节点一个不动，老玩家的树不受影响）：

```
                 时空锚点（根）
   ┌──────────┬──────────┬──────────┬──────────┬──────────┐
 速度支线    经济支线    研究支线    电力支线    稳定支线    宇宙支线
 （已有）    （已有）    （已有）    （新增）    （新增）    （新增，4 节点）
   +L4        +L4         +L4       1→2→6→12   1→2→6→12   1→2→6→12
 （新增第四层，价格 12 条）
```

**三条新支线的节点设计**（数值延续 4%~8% 一档）：

- **电力支线**（1→2→6→12，共 4 节点）
  1. 发电能力 +5%（1 条）
  2. 全厂耗电 -4%（2 条）
  3. 存电装置容量 +20%（6 条）
  4. 缺电降载更温柔：供电率低于 100% 时，产出惩罚减半（12 条；
     即 ratioDec 的惩罚项 ×0.5，不动供电率读数本身）
- **稳定支线**（1→2→6→12，共 4 节点）
  1. 污染产生 -8%（1 条）
  2. 净化器效果 +10%（2 条）
  3. 超频故障率 -10%（6 条，乘法叠加在现有 fault 公式上）
  4. 深渊腐蚀损坏率 -25%（12 条；没带深渊宇宙时此节点待机，不浪费——买了永远生效）
- **宇宙支线**（1→2→6→12，共 4 节点，**每个要求已拥有对应宇宙才能买**）
  1. 工业：并联折扣加深，边际增长 1.05^k → 1.04^k（1 条，需工业宇宙）
  2. 奥术：灵气充裕度加成上限 +10 个百分点（2 条，普通 +10%→+20%、魔法 +30%→+40%；需奥术宇宙）
  3. 深渊：污染驱动产出的斜率不变，但中性点从 30% 移到 25%（6 条；需深渊宇宙）
  4. 硅基：AI 误判率 5% → 2%（12 条；需硅基宇宙）

**原三支线补第四层**（价格 12 条，数值同本支线既有档位）：
采矿机/制造机再 +4%、GT 币再 +6%、算力再 +8% / 研究需求再 -8%。

**毕业线**：新增 4×3（新支线）+ 3×12（老支线第四层）= 48 节点价合计
`12+12+12+12`（新支线层价）与 `3×12`，全树总价从 **51 条 → 约 195 条**
（精确数在实装时按节点表算，目标控制在 180~210，即"打满一次大 MAX（200+ 条）买掉大头，
再补 1~2 次转生毕业"）。

**界面**：转生页的树从 660×330 容器扩到 660×520；老三支线整体上移收窄，
新增三支线放右侧；宇宙支线的未解锁节点显示锁与所需宇宙名。
存档无新字段（`rebirthNodes` 是 id 列表，老档自动兼容）。

**涉及文件**：`src/game/rebirth.ts`（节点表）、`src/numeric/rebirth.ts`（无改动）、
`core.ts` 各 `*Multiplier()` 追加新 effect kind 的累计、`RebirthPage.vue`（布局）、
`store.ts`（modifierRows 增加新来源行）。

## 四、M2 裂缝主动化：转生时机成为持续决策

**动机**：现在裂缝是一次性事件，"何时转生"没有决策空间。改造后裂缝变成
**每周目一次的主动提前转生**，任何时候可开，代价是收益打折。

**新规则**：

- 裂缝入口常驻（转生页 + 达到 LuV 时的教学弹窗各一处），本周目任何电压都能开
- 开启 = 立刻按**裂缝公式**结算并结束本周目：

  ```
  裂缝线缆 = floor( 0.3 × rebirthCables(本周目累计EU, 当前最高电压, x) ) + 1
  ```

  校验值：同一进度下 MAX 公式给 214 条时，裂缝给 `floor(0.3 × 214) + 1 = 65 条`；
  前期累计 EU 不足时保底 1 条不变（老设定：1 条刚好点亮一格）
- **每周目只能开一次**，开完周目即结束 —— 没有反复刷的空间
- 原 LuV 弹窗保留，但只作教学（介绍裂缝是什么、去哪开），不再是唯一的裂缝入口；
  "选了不转就永久关闭"的老限制取消
- 转生页常驻显示两行对比：「现在开裂缝拿 N 条」vs「打到 MAX 预计 M 条」，
  M 用当前 runEU 按公式外推（标注"预计"）

**对现有平衡的影响**：0.3 的系数让"早转"始终亏于"憋 MAX"，但把
「卡关时的止损 / 等不及时的加速」变成合法选项；配合 M1 的 195 条毕业线，
中期每条裂缝的 20~60 条都立刻有去处。

**涉及文件**：`src/numeric/rebirth.ts`（`riftCables()` 新纯函数 + 校验值测试）、
`core.ts`（`rebirth('rift')` 改走新公式、`riftPending` 只管教学弹窗）、
`RebirthPage.vue`（常驻入口 + 对比读数）、存档无需新字段（`riftOffered` 语义改为"教学已看过"）。

## 五、M3 挑战时间线：周目的专属目标

**动机**：周目内部没有任何专属目标。挑战 = 转生时自愿挂上的**周目规则修饰**，
全程生效，结算时校验，通过则线缆奖励加成 + 首通一次性大奖。

**规则**：

- 每次转生可选挂 **0 或 1 个**挑战（不叠加，叠加是数值失控的源头）
- 挑战失败没有惩罚：违规那一刻挑战静默失效，本周目照常玩、照常结算，只是拿不到加成
- 首次通关：线缆结算乘加成 + 解锁一条专属成就；重复通关：只拿乘加成（不再发首通奖）

**起步五个**（全部可用现有状态字段校验，不需要新系统）：

| 挑战 | 规则（全程） | 结算加成 | 设计意图 |
| --- | --- | --- | --- |
| 纯净时间线 | 污染从未超过 30% | ×1.3 | 净化器从可选修成必建 |
| 赤色时间线 | 污染从未低于 60%（需深渊宇宙，未拥有则不可选） | ×1.5 | 主动承受腐蚀风险 |
| 断网时间线 | 电网始终是普通电网（不解锁其余三种） | ×1.2 | 放弃 8%~15% 的耗电优惠 |
| 稳频时间线 | 供电率从未低于 95% | ×1.25 | 发电冗余成为硬约束 |
| 极限时间线 | 8 小时内打到 MAX（游戏内计时） | ×1.4 | 给熟练玩家的速通目标 |

**校验实现**：core 每拍在 tick 末尾对激活的挑战做一次布尔判定，违规只置一个
`challengeViolated` 标记；结算时 `gained × bonus`（若未违规）。判定全部是已存在的
状态（`pollution`、`grid`、`lastReport.powerRatio`、`playSeconds`），零新模拟逻辑。

**后续可扩**（不进首版）：挑战与宇宙的组合限定（如"只带工业宇宙打赤色"）、
难度星级、隐藏挑战（由成就触发揭示）。

**涉及文件**：`src/game/challenges.ts`（新文件：挑战定义与判定纯函数）、
`core.ts`（挂接 / 校验 / 结算）、`save.ts`（v19：`activeChallenge`、`challengeViolated`、
`completedChallenges` 三个字段）、`RebirthPage.vue`（转生时的挑战选择卡 + 当前挑战状态）。

## 六、M4 时空折叠：线缆的第二去向（周目商店）

**动机**：树是"永久但贵"，缺一个"当周目见效但便宜"的去向，两者抢线缆形成取舍。
折叠增益**只在本周目生效，转生清空**，定价原则是"长期重复买略亏于同额投树，
但当下见效快"。

**商品**（转生页第二栏，随转生重置）：

| 商品 | 效果 | 价格（暂定） |
| --- | --- | --- |
| 开局快递 | 转生后立刻送 5 台 ULV 采矿机 + 3 台 ULV 发电机 | 1 条 |
| 开工资金 | 每一级 GT 币钱包 +100 枚（按当前最高电压发） | 1 条 |
| 折叠加速 | 本周目全厂产出 ×1.1（与加成树乘算） | 3 条 |
| 超频执照 | 本周目超频故障率减半（与稳定支线叠乘，封底 -50%） | 2 条 |
| 折叠电池 | 本周目存电容量 ×2 | 2 条 |

**约束**：

- 每种商品每周目限买一次（避免无限刷加速）；总价上限 9 条/周目，
  对照中期一次转生的 20~60 条，花在折叠上永远少于投树，但见效是"这一周目立刻"
- 折叠加速 ×1.1 会抬高本周目累计 EU，从而抬高线缆结算 —— 这是**设计上的自洽回路**
  （投 3 条大概率在结算时赚回来一点），实装后用 `npm run balance` 校验不构成永动

**涉及文件**：`src/game/fold-shops.ts`（新文件，纯数据 + 购买判定）、`core.ts`（购买与效果挂接，
多数效果走现有的 rebirth effect 通道加一个"per-run"来源）、`save.ts`（v19：
`foldBought: string[]`）、`RebirthPage.vue`。

## 八、C2 终局装置（可选，MAX 之后）

两档方案，**建议先做轻方案**，重方案留待轻方案验证后再拍板：

- **轻方案「普朗克锚」**：线缆的终极 sink。花 300 条买一次（永久），
  之后每次 MAX 路线转生的线缆结算 ×1.5（裂缝不受影响）。
  一句话定位："毕业后的第 300 条线缆仍然有去处"。实现量约等于一个特殊树节点。
- **重方案「奇点收束」**（二阶转生，远期候选）：线缆攒够 1000 条可"收束时间线"——
  重置整棵树与全部宇宙，得 1 枚「奇点」；奇点兑换跨收束的规则级加成
  （全厂产量 ×2 / 新增第五宇宙 / 结算公式升档）。改动面大（等于第二套 prestige），
  且需要先设计第五宇宙的内容，**本大纲不展开**，只留这个坑位。
