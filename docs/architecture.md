# 项目架构与界面约束

## 模块边界

| 层 | 入口 | 职责 |
| --- | --- | --- |
| 内容 | `src/content/` | 电压、资源、机型与模板的 JSON 定义；注册器检查引用并生成运行目录 |
| 数值 | `src/numeric/` | 纯公式、大数运算、数值格式化；不读取 Vue、存档或浏览器状态 |
| 玩法 | `src/game/core.ts` | 持有游戏进度，执行建造、研究、转生与单步结算 |
| 核心实例 | `src/game/engine.ts` | 当前唯一的 `GameCore`；读档和重置整体替换 |
| 时间推进 | `src/game/runtime.ts` | 墙钟计时、逐秒推进、长时间补算分片与取消；不依赖 Pinia |
| 存档 | `src/game/save.ts` | 序列化、版本清洗、本地读取与导入；资源数量存十进制字符串 |
| 日志 | `src/game/log.ts`、`diagnostics.ts` | 有界事件留存、筛选、异常现场与用户主动导出的诊断报告 |
| 呈现 | `src/game/presentation/` | 从核心生成只读快照；按设备、资源、进度、宇宙与厂区分模块 |
| 操作协调 | `src/game/store.ts` | 玩家操作入口、模拟调度、存档生命周期与反馈；不写数值展示公式 |
| 视觉场景 | `src/scene/` | Three.js 厂区、相机与采矿反馈；只消费快照，不修改游戏进度 |
| 页面 | `src/components/*Workspace.vue`、`RebirthPage.vue` | 工厂、科技、星图与设置；`App.vue` 只协调导航、页面缓存、主题和启动/销毁 |
| 样式 | `src/styles/` | `tokens.css` 主题、`base.css` 基础元素、`components.css` 功能组件、`workspace.css` 页面与场景 |

`presentation/snapshot.ts` 只组装数据。各子模块不得反向导入 store；场景不得读取可变的核心实例。
快照整体替换并通过 `markRaw` 跳过深层代理，内部字段不能由组件直接修改。
星图目录、挑战选项、转生履历与成就列表按实际输入缓存，输入未变时复用只读对象；线缆、节点、宇宙、挑战、履历、成就或数字显示模式改变时更新对应结果。缓存按核心实例弱引用隔离，读档、重置与新周目不会继承旧核心的结果。转生效果合计按节点列表内容缓存，购买和撤销立即生效。
设备种类的显示顺序和说明以 `presentation/catalog.ts` 为准，操作按 `models.ts` 导出的完整机型目录查找，目录由内容注册器生成。
自定义字段、稳定标识与扩展操作见 `custom-content.md`。

## 数据流

```text
玩家操作 → store → GameCore → 呈现快照 → Vue 控件 / 3D 厂区
实际经过时间 → ElapsedClock → store → advanceSimulation → GameCore.tick
GameCore → 序列化 → 浏览器本地存储 / 用户主动导出的 JSON
```

资源结算顺序仍由 `GameCore.tick` 控制；不能把耗电、燃料、生产等顺序依赖改成任意事件订阅。
音效、日志与粒子属于反馈，不参与资源计算；场景动画使用独立时钟。

## 时间与生命周期

- 在线读取真实经过时间，不假设浏览器定时器每次都准时执行。
- 在线与离线都按一秒推进，最后不足一秒的部分按实际余数结算。离线时长上限由 `runtime.ts` 定义。
- 补算按执行时间分片并让出线程，界面显示进度；不能用后台停止运行的 `requestAnimationFrame` 等待补算。
- 补算期间不叠加在线结算，也不开放进度修改控件。重置、导入、卸载会取消旧补算。
- 补算中途存档使用已完成的时间点，避免刷新或关页后丢掉尚未补算的时间。
- `store.stop()` 清理模拟/存档定时器、浏览器事件和状态订阅；重复启动不累积监听。

逐秒补算比大步近似更耗时，但燃料耗尽、储能、随机事件和研究完成的口径可与在线一致。
优化补算时必须保留这一约束，不能只为加速把一小时当作一拍结算。

## 日志与诊断

- 日志仅保存在内存和浏览器本地存储；复制与下载由玩家主动执行，不连接日志服务器。
- 事件统一包含稳定标识、级别、分类、发生时间、游戏时间、打开会话及当时的版本和构建信息。旧记录缺少的版本标为未知，不套用当前版本。
- 关键操作记录实际结果。建造、出售、升级及资源调整保留变化前后值；正常的条件不满足和手动采矿归入默认关闭的调试级别，调试开关只影响本次打开。
- 连续相同事件只在同一会话、相同现场且相邻时合并，保留实际次数和首末时间。容量满后先淘汰低级别的旧记录，全部同级时淘汰最旧记录；上限和合并窗口以 `log.ts` 为准。
- 普通事件延迟批量写入，首次警告和错误立即写入；离线补算期间按拍收集事件，批量通知与写入。隐藏或关闭页面时保存尾部记录。存储失败仍可浏览、复制和下载，并可重试保存。
- 替换核心后同步日志的状态基线；模拟事件使用结算后的游戏时间。离线补算也记录中途完成的研究等关键事件，但不逐拍播放音效。
- 面板支持级别、分类、关键词、最后发生时间和本次会话筛选，按需加载更早记录。TXT 与 JSON 导出始终包含全部留存记录、环境和当前状态，不受筛选或分页限制；不附带存档正文。
- 错误未读提示使用事件序号，清空、轮转和重复合并后仍能发现新错误。异常文本或现场快照读取失败不能阻断记录和报告导出。

规范参考：[游戏日志系统](https://www.edwardrio.com/game-engineering/07-%E6%B8%B8%E6%88%8F%E6%97%A5%E5%BF%97%E7%B3%BB%E7%BB%9F.html)；按本地单机游戏的范围采用分级、结构化、关键操作留痕、批量写入和查询原则。

## 界面与视觉

- 桌面工业控制台：左侧常驻导航与电压等级、横向资源库存、中部厂区与设备工作台，右侧矿脉/电能/研究/污染/扩张操作栏；窄屏时操作栏移到工作台下方。
- 主厂区使用 `FactoryScene3D.vue` 与 `scene/factory3d/`，以 Three.js 呈现方块机器，支持旋转、平移、缩放、WASD 和升降；标记及操作保持为真实 DOM 按钮。
- 设备编号从渲染器中的同一相机投影，点击机体使用 Three.js 射线拾取；远景隐藏编号，避免重叠。
- 当前只实现 LV 六种工业机器，均为单方块。魔法机器与灵气节点暂不匹配；其他电压及多方块尚未接入，不使用臆造结构代替。
- 默认进入 LV 演示模式，各展示一台；演示运行与暂停不修改数量、资源或存档。实际厂区读取快照中的机型数量和运行台数，生产活动仍采用现有快照的类别汇总粒度；待机不播放生产粒子。
- 厂区与设备工作台共享一个选中类别。工作台只渲染当前类别，内容视口高度稳定并在内部滚动；重复点击当前类别不收起，切换不做高度动画。机器本体和名称标记都可点击选择，明确点击「打开工作台」才滚动跳转。切换类别只重置内部列表的滚动位置，不移动整个页面。
- 四个页面首次访问时创建，切换时缓存。工厂保留相机、显示模式与设备选择，星图保留平移位置，设置保留输入和日志筛选。离开时暂停场景绘制、采矿与星图动画，日志面板取消订阅且不标记新日志已读；返回时同步当前数据。游戏卸载时释放页面与场景资源。
- 绘图限制为 30 帧/秒，像素比最多为 1.5；离开可视区域或切后台停止绘制，关闭动态效果后只在交互、尺寸或状态改变时重绘。
- 动态画面开关是独立本地偏好，不进入数值存档；关闭后暂停持续动画，手动采矿保留点击反馈。系统减少动态效果同时关闭持续动画和点击动效。
- 主题颜色与材质以 `tokens.css` 为唯一来源；电压配色以 `src/content/voltages.json` 为准，CSS 变量和素材脚本从中派生。暗钢与原版亮灰复用已有 GT 面板、按钮及插槽贴图，不换成通用蓝绿控制台；经典深色选项保留。数字使用本地字体，不请求远程素材。

机型原型、贴图配方与每种可见台数由 `src/content/scene-machines.json` 定义；名称与类别从内容注册器读取。超过可见容量后聚合展示，真实台数不变。

机器各面使用 Modernity-GTNH 原始 PNG，将机壳和透明覆盖层合成，动画按原包帧序及 tick 时长播放。提取器为 `scripts/extract-factory3d.py`，逐张路径及机型各面配方以 `src/assets/factory3d/manifest.json` 为准；不借用相似机器贴图。

地板复用 `gtnh3d/src/layout.js` 的 `placeFloor`、原蓝图数据与体素网格化器，保留三层及 2×2 拼接；坐标解码与校验约束见 `gtnh3d/README.md`。矿脉动画继续使用现有素材。

手动采矿卡片使用 `pickaxe.veinTier` 对应的实际可采矿脉。鼠标落点换算到矿石自身坐标，键盘和文字区点击从矿石中心反馈；系统减少动态效果时不创建粒子，连续点击的粒子数量有界，卸载时取消回调。

资源格只显示名称和库存。点击后在独立的整行区域显示收支，不在窄格内悬停展开。

发电主读数和工作台汇总采用上一模拟拍的实际发电量除以步长；额定能力保留在独立说明和明确标记的明细列中，不冒充实际输出。

## 构建与验证

运行命令和产物以 `status.md` 为准。Web 目录与便携 HTML 使用同一套源码和同一次 Vite 构建。
便携打包不能删除 Web 目录；本地游戏不依赖外部服务器、账号或网络资源。

单元测试覆盖数值与玩法、存档清洗、在线/离线一致性、补算取消、部分存档时间和场景快照适配。
跨模块交互需通过实际浏览器入口验证：采矿、矿石建造、停机恢复、页面导航、主题、存档往返与减少动态效果。
浏览器验证使用独立测试上下文，不读取或覆盖用户正在玩的存档。
