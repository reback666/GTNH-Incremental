# 玩法与画面重规划执行计划

## 适用范围

本文是后续重规划需求、执行顺序和待确认项的唯一来源，不代表功能已经实现。现行规则见 `../plan.txt`，当前实现与操作见 `status.md`。

0.9.0 整合现有已完成内容、版本升级和文件清理，不实施本文的新玩法。下列方案仍需完成待定项核对和整体确认，不能把推荐选项视为用户决定。

## 已确认边界

### 目标与成长

- 工业提供无需转生、无需高风险能源也可完成的主线；其他体系提供可选的独特收益。
- 材料生产是核心：资源加工成材料和关键零部件，用于建设和阶段工程；GT 币只辅助补买基础原料，来自允许交易的基础物资。
- 保留有代表性的加工步骤，合并重复的小步骤；旧设备可继续承担基础生产，不强制淘汰。
- 每阶段以代表性工程突破；只展示当前、下一阶段和少量远期目标。建议目标可关闭。
- 首轮目标为现实时间三到七天，首次自动采矿约五分钟；均是待验证的节奏目标。自动化后不要求持续点击劳动。

### 生产管理

- 全厂共享仓库，自动取料和存入产品；位置不影响产能，不要求手动布线或铺管。
- 同类机器分成生产组，每组选择产品和台数。默认目标库存生产，另有持续生产和指定批量。
- 同产品共用全厂库存目标；创建时提供可编辑建议值，后续需求变化仅提示，不擅自修改。
- 取料和供电复用生产组优先级。工程材料可主动预留、随时释放，不被其他生产和交易消耗。
- 生产链建议需展示所需机器与分组变化，确认才应用，不擅自购买设备；多配方优先展示已解锁且现有设备能执行的方案。

### 能源、风险与离线

- 按电压组织供电，变电设施自动连接和调度；升降压受容量限制，不增加总功率，也不让低级机器越级执行配方。
- 普通可调发电按用电和充电需求调节；支持超频的普通机器可安全提速，耗电显著增加，不因此永久损坏。
- 永久事故只属于核能等高风险能源及逐项确认的少数特殊加工设施，不设全机器通用危险档。投用前告知，风险由具体运行条件决定。
- 风险累积速度、临界线及异常可见；只预警，由玩家干预，不提供事前自动停机保护。离线保持原运行与风险。
- 一次事故仅永久损失危险组内一台设备，不波及其他组或仓库；剩余设备退出危险运行，不自动重建，具体安全处置待逐设施确认。
- 在线、离线采用相同生产条件和效率，最多补算七十二小时，不替玩家决定或完成需要主动确认的阶段操作。

### 画面与交互

- 电脑、手机均完整可玩；厂区、工作台在同页。电脑首屏包含紧凑厂区、当前目标和工作台前几行，操作栏在右边。
- 手机同页上下排列，厂区可折叠；底部固定工厂、工程科技、星图、设置四个主入口。手机页内操作位置仍待确认。
- 仓库、配方为随处打开的查询面板：电脑侧边，手机全屏；关闭恢复原选择、位置和视角。
- 玩家选择的主题保持稳定，控制中心采用对应主题材质。时代变化主要由厂区、设施和局部强调表现。
- 机器图标使用启用 Modernity 的 GTNH 客户端原生完整物品图标，不以手绘、拼贴或染色图代替；素材依据见 `../scripts/texture-sources.md`。
- 默认俯斜概览，可旋转、平移、缩放和一键复位。按组分区，新增主要追加，已有位置尽量稳定。
- 数量扩张是核心奖励，允许后期上千台乃至更多同类机器，尽量逐台呈现，不擅自设置展示数量上限或改成少量代表机器。
- 点机器先选中、显示摘要并同步工作台；明确点击管理才滚动定位。选中时展示输入、输出与共享库存的逻辑关系，不伪装成实体运输线路。
- 工作台按类别切换生产组和建造设备；当前阶段默认展开，旧阶段折叠并保留产出摘要，异常不随折叠隐藏。
- 生产组默认显示产品、运行与总台数、实际产速、耗电、状态；额定与实际分开，手机分行。
- 默认库存显示当前阶段和追踪目标相关资源，顺序稳定；全局持续显示具体异常并可定位。
- 日常动效克制，首次关键建设、工程和时代突破加强反馈，提供减少动态效果的选择。

## 执行顺序与验收

| 阶段 | 工作内容 | 开始条件 | 验收结果 |
| --- | --- | --- | --- |
| P0 方案收敛 | 明确起步、阶段工程、终点、研究、污染、危险设施与转生；形成阶段内容表 | 继续核对已提出但未回答的问题 | 已确认与未确认清楚分开，用户整体确认后才进入制作 |
| P1 最小生产闭环 | 做通一条资源到材料、关键零件、工程的链，接入生产组、共享库存、生产模式、优先级和预留 | P0 的对应规则确认 | 从实际入口建造、分组、补库存和完成工程；无需持续点击，也不出现库存争抢造成的错误消耗 |
| P2 能源与结算 | 电压网络、变电容量、调度、普通超频及按需发电；接入一致的离线结算 | P1，能源细则确认 | 缺料缺电只按规则停机或调度；在线与离线在相同条件下结果一致，工程不被自动确认 |
| P3 双端主界面 | 厂区、工作台、目标、库存、右侧操作、查询面板、主题材质和全局预警 | P1 可实际游玩，手机操作方式确认 | 电脑与手机均能完成建造、管理、查询和异常处理，关闭面板不丢位置，文字和操作不重叠 |
| P4 大规模厂区 | 分区稳定扩展、逐台设备、自由镜头、选择联动、批量管理与导航 | P3，导航及批量范围确认 | 上千台规模仍可观察、定位和管理；运行表现对应实际状态，不以聚合数量替代已确认的逐台展示 |
| P5 完整主线 | 按确认后的阶段表扩展材料、配方、设备、研究和工程，检验新旧设备取舍 | P1 至 P4 闭环成立，阶段内容确认 | 安全工业路线能完整通关；新阶段不只是换数字，首次自动化和首轮耗时目标经实际验证后再定参数 |
| P6 可选长期内容 | 已确认的高风险设施、其他体系、自愿转生和长期奖励 | 各条路线独立确认，工业主线完整 | 不强迫核能或转生才能完成主线；逐项验证事故、离线预警、损失范围和事故后状态 |
| P7 整体验收 | 检查成长反馈、回归概览、双端操作、性能、存档和材料供需 | 前述阶段分别通过验收 | 从新开局到终点可实际游玩；回归能看懂变化，机海管理不依赖逐台重复配置 |

每阶段按可独立验证的完整改动推进，不同时重写所有系统；验证与测试围绕该阶段的真实失败风险，不为低风险展示细节堆积检查。
